# Guinea Orchard

A cosy, office-friendly co-op farm for everyone on the LAN: up to 12 farmers share one farm. It starts small (the barn, the yard and 12 guinea pigs) and grows: buy squares of land in the shop, and the piggies breed. Feed them by throwing veg (they come running, wheeking), harvest and replant the veggie garden, gather apples in the orchard, fill the bowls in the barn, carry sacks from the feed bin to top up the pellet hopper, pick piggies up for a health check (weigh, nails, mites, sniffles, teeth: find problems and fix them), and shoo foxes and hawks before they carry anyone off. There's a barn (inside: walls drop and the roof comes off when you walk in) and the land around it, a 3×3 grid of squares (yard, veg patches, orchard, hay meadow, hut meadow, wild flowers, pond). Day turns to night; at dusk farmers serve the salad platter they've made up in the barn and everyone comes in for supper; at night the pigs sleep and foxes come more often. Each morning the farm gets a report card and coins for how the day went, to spend in the shop (B) on upgrades. **No sound** (office PCs have none): pigs "say" everything in comic bubbles ("WHEEEK!", "monch monch", "zzz", "EEK!"). Sister project to `~/countersmack` (same toolchain and server pattern; that one is a brawler, this one is deliberately non-violent: carried-off pigs come back under the fence later, shaken).

Stack: Vite 8 + TypeScript 6 + three.js + `ws`, tested with Vitest 5, linted with oxlint. No React. All art is three.js primitives and canvas textures; no asset files.

## Commands

| Command | What it does |
|---|---|
| `npm run dev` | Dev server + farm server on port 5173, reachable on the LAN |
| `npm run build && npm run preview` | Production build on port 4173 (farm server runs there too) |
| `npx vitest run` | Tests (`npm test` = watch mode) |
| `npx tsc -b` | Type-check app, server and tests |
| `npm run lint` | oxlint |

**Checkpoints:** every half hour of farm-clock time the server writes `data/checkpoints/dayNNN-HHMM.json` (the last 48, plus the 6am one of the last 14 days). `npm run restore` lists them, `npm run restore -- day003-1430` loads one (it refuses while a server is running on 5173/4173, since a server saves over the farm when it stops; the old save goes to `data/farm.before-restore.json`).

Find the LAN address with `hostname -I` (ignore `169.254.*`). If another computer can't connect: `sudo ufw allow 5173/tcp`. Delete `data/farm.json` for a fresh farm. Saves are versioned (`FarmSave.v`, now 2); a save of another version is ignored and the farm starts fresh.

## Working with this user

- **The user does the visual checking.** Don't install Playwright/Chromium for screenshots. Verify with tests, `tsc` and lint, then say what to look at in the browser.
- Ask before `git init` / committing.
- Something reformats files on save (long lines get wrapped): re-read before editing.

## How it works

- **Server** (`server/plugin.ts`): a Vite plugin that attaches a WebSocket server at `/ws` to Vite's HTTP server (dev and preview); Vite's hot-reload socket is untouched. One farm per server. Ticks every 50 ms: `farm.tick(dt)`, sends queued messages, broadcasts a snapshot. The farm is saved to `data/farm.json` every 20 s while anyone's on, when the last farmer leaves, and on close; it's loaded on start (a broken save is ignored).
- **Farm clock:** `Farm.t` only advances while at least one farmer is on, so the pigs don't starve overnight. Days start short and get longer: day 1 is `FIRST_DAY_MS` (4 min), growing each day to `DAY_MS` (8 min) from day `DAY_RAMP` + 1 (`dayLength`). `farmDays(t)` turns farm time into days-with-fraction (`Farm.days`; `day` and `dayTime` come from it) and `farmTime(days)` goes back (handy in tests). Night is the last quarter of each day (`NIGHT_START`); once every pig is in the barn asleep (or heading to bed) for `SLEEP_SKIP_MS` with no predator about, the clock jumps to just before dawn (`skipNight`). `clockHours` turns time of day into the 6am–6am clock the HUD shows. Predators wait `FIRST_PREDATOR_MS` after the farm wakes.
- **Authority:** farmers own their own movement (sent 20×/s, pushed out of solids by the server). The server owns everything else: pigs, food, crops, bowls, baskets, predators. Interactions (`plant`, `harvest`, `fill`, `gather`, `pickup`, `treat`…) are requests the server checks (distance, basket room, state).
- **Pig brain** (`Farm.updatePig` / `decide`): hunger falls over time (slower asleep); grazing outside slows it. Danger first (flee to the nearest hidey hut or the barn), then begging near a farmer with veg, then the current state. Food landing excites every peckish pig within `EXCITE_RADIUS` → `seek` (client shows WHEEK) → `eat` (bites every `BITE_MS`, client shows monch). Bowls are foods with ids 0–3 that never go away. They love snacks: below `SNACKY` they trot to veg/apples on the ground, and by day `SNACK_TRIP` sends them under an apple tree (graze) or to the garden fence by a ripe bed (beg at it; `snackSpot` / `arrived`). Pigs path between inside and outside only through the barn door (`nextStep` in map.ts, with per-pig lanes so they don't jam); anything stuck for 1.5 s rethinks. Pigs overlapping get pushed apart (eating/sleeping/hiding ones stay put).
- **Health:** problems are bit flags (`ISSUE_BIT`) that start at random (`ISSUE_RATE`; sniffles only from being outside at night). Mites make pigs scratch, sniffles make them sneeze; nails and teeth only show up in a health check. The check card (`hud.ts`) reveals each result after a short "checking…", then offers the fix.
- **Predators:** foxes sneak in from the west/east/south fence (slowly under the fence), go for the nearest exposed pig (outside, not in a hidey hut), pounce in the last few metres, then carry it slowly back under the fence. Pigs only notice a fox up close (closer still when eating). Hawks circle for a while (scaring pigs within `HAWK_FEAR`), then swoop. `F` shoos anything within `SHOO_RADIUS` (hawks a bit further) and makes it drop its pig. A pig that's carried off turns up at the south gate `LOST_MS` later, unhappy.
- **Pellets and hay:** hoppers are fixed food sources like the bowls (food ids `HOPPER_ID`+i, kind `'pellets'`). `sack` at the feed bin picks up/puts back a sack (hands full: no throwing or pig pickups); `pour` adds `SACK_PELLETS`. The second hopper only works once bought. Pellets are rationed: `Farm.sacks` is one per built hopper, restocked at dawn; when it's 0 you just can't take one (the prompt explains). Hay is the main food: with the hay meadow, `hay` on one of its `HAY_PATCHES` (a 4×4 field of tall hay; `hayPatchAt`) cuts an armful (`Farmer.hay`, hands full) and the patch regrows over `HAY_REGROW_MS` (`Farm.hayField`, sent as `hayField` 0..1 and drawn as stalks that grow back); putting it back undoes the cut, `rack` puts `HAY_ARMFUL` into one of the `HAY_RACKS` in the barn (fixed foods from `RACK_ID`, kind `'hay'`, eaten from the floor in front). A pig that ate hay in the last day (`hayAt`) rarely gets bad teeth (`HAY_TEETH`); the report pays `PAY.hay` per pig that had hay.
- **Money:** one shared wallet (`Farm.coins`, starts at `START_COINS`). `payDay()` runs at dawn: happiness, well-fed pigs, fixes, rescues, minus carried-off pigs, pigs out after dark and pigs still poorly (`PAY`), sent as a `report` (with 1–5 stars, `STARS`). `buy` spends it on `UPGRADES` (one each); their effects live next to the rule they change (`basketMax`, `hopperMax`, `harvestYield`, `growMs` in rules.ts; fence/scarecrow/orchard/heater checks in farm.ts) and `World.setUpgrades` shows the ones you can see (second hopper, scarecrow, sprinklers, heater, compost heap, wire on the fence, second veggie patch). The second veggie patch (`GARDEN2`, NE corner) is always fenced and solid; its beds (`BedDef.garden === 1`) only work once bought (`Farm.bedOpen`); before that it shows weeds and a for-sale sign. Coins, upgrades and hopper levels are saved (older saves load with the defaults).
- **Land** (map.ts): `SQUARES` is the 3×3 grid (`GRID`), `LAND` in rules.ts has each square's name, cost and description. `Farm.land` is what's owned (starts `START_LAND`: barn + yard); `land` message buys a square that `canBuy` (next to owned land). The map module holds the current land (`setLand`; the farm calls it on every tick/message as there's one map and tests make many farms, the client calls it from snapshots) and refills `FENCE_EDGES`/`FENCE`, `PIG_SOLIDS`, `FOX_SOLIDS`, `FARMER_BLOCKS` from it: only owned squares' things (garden fences, trees, huts, hay, pond) are solid, and the fence runs round the owned squares. Pigs and food stay on owned land (`onFarm`, `settlePig` pulls things back on, `pigCanStand`); farmers can roam anywhere (hop the fence). Foxes spawn outside a non-barn fence edge, exit straight out through the nearest edge that isn't blocked (`exitFrom`, `crosses`), and are slow near the fence (`atFence`). Square effects: hay meadow grazing fills tummies faster (`LUSH_GRAZE`), wild flowers cheer grazing pigs (`FLOWER_HAPPY`), resting by the pond too (`POND_HAPPY`). Things only exist once their square is owned: beds (`bedOpen`), `hideys()`, `trees()` and apples, `gardens()`; jobs and upgrades can `needs` a square. World.setLand shows owned squares' things and puts long grass and a for-sale sign on the rest; the shop has tabs (`SHOP_TABS`), Land first with a little map.
- **Breeding** (`Farm.breed`, each tick): a happy, fed adult sow, with an adult boar on the farm and room for the litter, conceives at `PREGNANCY_PER_DAY` (low). `due` (on the look, in farm days: `Farm.days`) is `PREGNANCY_DAYS` later; while expecting she gets hungry faster (`PREGNANT_HUNGER`) and `careGood`/`careTotal` track how long she's been kept at `CARE_OK`+ hunger and happiness (cuddles count `CARE_CUDDLE_S`; shown as `care` on the snapshot and the check card). `giveBirth`: 1–4 pups by `LITTER`, at most 2 if care < 50%, 1 if < 25%, capped by `herdMax`. Pups (`age` 0, `born` in farm days) are drawn growing from half size, always stay by mum, and grow up after `PUP_DAYS`.
- **Salad night:** farmers put veg from their basket into the platter at `SALAD_TABLE` (`salad` message, up to `SALAD_MAX`); it's ready at `SALAD_MIN` veg of `SALAD_KINDS`+ kinds and can be served (`serve`) from `SALAD_FROM` (just before nightfall), once a night. Served, it's a fixed food (`SALAD_ID`) at `SALAD_SPOT` with `SALAD_BITES` per veg; every pig that isn't full is excited towards it (they come in through the door) and the rest go home. Each bite gives 2 + the number of kinds in happiness; the report pays `PAY.salad` + `PAY.saladKind` per kind. There's a dusk reminder; leftovers are cleared at dawn.
- **Pigs as people:** `PigLook` also carries the things that change rarely: `name` (renamed from the check card), `adopter` (farmer name, ⭐), `friend` (pairs `id ^ 1`; they hang out, a pig is sadder while its friend is carried off and cheers when it comes back), `mum`/`born` and `due` (see Breeding) and `rosettes`. Any change is broadcast as a `pig` message (also how clients hear of a birth); `welcome` sends them all. Pig ids are indexes into `Farm.pigs`, which can grow (up to `herdMax`).
- **Each dawn** (`payDay` → `newDay`): pay (now with the craving line and, every `SHOW_EVERY` days, the pig show: `bestInShow` gets a rosette and `SHOW_PRIZE`), then a new `craving` (a bite of it gives `CRAVING_HAPPY`), `JOBS_PER_DAY` new jobs, maybe a rain shower (`rainFrom`/`rainTo`), and the barn door opens. A fresh farm's craving and jobs are picked without the dice so seeded tests don't shift.
- **Jobs and the diary:** `Farm.credit(name, stat)` is called wherever a farmer does something (`STATS`); it counts towards today's jobs (paid `JOB_PAY` the moment one is done) and the all-time `diary` (by farmer name, saved). The diary is sent on request (`diary` message, client asks every 3 s while it's open with `L`). Food remembers who put it out (`Food.by`) so wheeks (pigs that came running) are credited.
- **Barn door:** `doorShut` (`door` message near `DOOR_MID`). Shut: pigs are pushed out of `DOOR_GATE`, don't cross to food or wander across, and shut-out pigs queue at the door begging (`waitAtDoor`). Farmers step over it. Foxes can only get into the barn at night with the door open (`barnOpen`: inside pigs then count as `exposed` to foxes, foxes route with `nextStep` via `foxStep`, and can always squeeze back out).
- **Zoomies:** the zoomometer (`zoomMeter`, 0..1, in the snapshot and under the clock) charges while the herd's average happiness is at least `ZOOM_HAPPY` (in `ZOOM_FILL_MS`, faster when happier), drains below it and rests at night. When full: `ZOOMIES_MS` of happy pigs alternating popcorns and short dashes (`zoom` state), then it starts again from empty. **Rain**: calm pigs go in (`goIn`), wanders stay inside, sniffles can start outside, growing beds go `RAIN_GROW`× faster; the client greys the sky and draws rain and puddles (`World.update`).
- **Emotes and jumping:** Z X C V send `emote` (`EMOTES`), broadcast to everyone as a bubble over the farmer. Movement has momentum (`moveFarmer` in move.ts, run by the client: `FARMER_ACCEL`/`FARMER_STOP` on the ground, only `AIR_ACCEL` of steering in the air, walls take away speed). Space jumps for real (`JUMP_V`/`GRAVITY`), keeping your speed: farmers have a feet height `y` (sent in `state`, shown in the snapshot). Every farmer obstacle is a `Block` with a height (`FARMER_BLOCKS`): `settleFarmer(p, y)` only pushes you out of things taller than your feet, and `groundAt` is what you land on. Garden fences (0.75), the farm fence (1.2), hidey huts (`HIDEY_H`) and hay stacks (1.4) can be jumped onto or over; barn walls and trunks can't. Farmers can roam all the land and `FARMER_ROAM` beyond it. Click throws.
- **Client** has no pointer lock: the mouse aims at the ground (throws land there, capped at `THROW_RANGE`), right-drag turns the camera, the wheel zooms. Bubbles are client-side, driven by pig state changes plus periodic chatter (`Game.chatter`), only for pigs within `CHATTER_RANGE` of you.

## Code map

```
src/core/            Shared by browser and server (no DOM). Imports use .ts extensions so Node can load them.
  rules.ts           ALL gameplay numbers (pellets, pay, upgrade prices and effects, speeds, hunger, bites, basket size, grow time, issue rates, predator timings, day length)
  map.ts             The layout: the 3×3 grid of land (SQUARES, canBuy), the barn + door, salad station, gardens + beds, orchard trees, hidey huts, hay, pond, bowls, pig houses. The current land (setLand) and everything that follows from it: fence, solids per kind (farmer blocks with heights, pig, fox), onFarm. pushOut collision, groundAt, nextStep door routing
  pigs.ts            PigLook (name, breed: smooth/abyssinian/peruvian/teddy, coat pattern + colours, sex, age, weight) and makePigLooks
  farm.ts            Farm: the whole simulation, no networking. Feed it messages + tick(dt); read `out`. save()/load
  protocol.ts        ClientMsg / ServerMsg types, parseClientMsg (validates everything from the wire), cleanName
  move.ts            moveFarmer: a farmer's momentum, jumping and landing (run by the browser, tested here)
  vec.ts             facing(yaw), yawTowards (yaw 0 looks down −Z)
src/client/
  game.ts            Main loop: walking, camera, aiming, E-action picking + prompt, throwing, syncing pigs/farmers/food/predators from snapshots, bubbles, predator edge arrows, hover tooltip
  world.ts           The static scene from map.ts (barn with removable roof, garden beds with growing crops, orchard, hidey huts, fences, trees beyond) + bowls' food piles + day/night lighting and lamps
  pig.ts             PigModel: built from the look; pose() animates walking, eating, grazing, sleeping, popcorning, begging, being held/carried
  critters.ts        FarmerModel (straw hat, overalls in their colour, wellies, basket), FoxModel, HawkModel (+ ground shadow), textSprite
  veg.ts             makeVeg (carrot, lettuce, cucumber, pepper, apple), icons, shared materials
  bubbles.ts         Comic speech bubbles as sprites (cached canvas textures, one per thing at a time)
  hud.ts             DOM overlay: clock, coins, farm stats, shop, end-of-day report card, farmer list, alert feed, toasts, basket slots, action prompt, health check card, predator arrows, tooltip
  input.ts           Keyboard (WASD/arrows, Shift, E, F, 1–5, Space, H, Q/R) and mouse (aim, click, right-drag, wheel)
  net.ts             WebSocket to ws://<same host>/ws
src/main.ts          Lobby (name + overalls colour remembered in localStorage `guinea.name` / `.color`, a spinning random piggy), connects on load for `info`, starts Game on `welcome`
tests/core/          farm.test.ts: feeding, pellets, money and upgrades, garden, health checks, foxes and hawks, night, saving, a 5-minute soak that no pig gets stuck in a wall. fun.test.ts: craving, jobs, names/adopting, emotes, jumping, zoomies, rain, barn door, breeding, land, salad night, momentum, friends, pig show, diary. helpers.ts: seeded farm setup
server/plugin.ts     The farm server (Vite plugin): ticks, snapshots, saving. checkpoints.ts: the half-hourly checkpoints. restore.ts: `npm run restore`
tests/server/        Real HTTP + ws server filled to MAX_FARMERS + 1; checkpoints
```
